# 🧩 How I Think About Software

I like systems that follow this progression:

```text
              DATA
                ↓
             STRUCTURE
                ↓
            AUTOMATION
                ↓
          INTELLIGENCE
                ↓
             ACTION
```

Not:

```text
"Let's add AI."
```

But:

```text
"What problem exists?"
        ↓
"What data represents it?"
        ↓
"Can software automate it?"
        ↓
"Can ML improve it?"
        ↓
"Can AI make it easier to use?"
```
